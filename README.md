# 💫 About Me

I'm a **Product Designer building AI-powered products** at **UXMagic.ai**.

I've spent the last few years working across startups, SaaS, freelance projects, and early-stage products, often operating across the full product journey:

**Problem → Research → UX → UI → Prototype → Motion → Build → Ship**

I enjoy working where **design, technology, and product strategy overlap**.

Currently, I work on AI-powered product experiences at UXMagic, while also building and experimenting with products on my own.

### What I care about

- 🧠 **Product thinking over pixel pushing**
- 🔄 **Flows and systems over isolated screens**
- 🤖 **AI as a product primitive, not a gimmick**
- 💻 **Designers who understand how things are built**
- 📈 **Design that improves real product outcomes**
- ✨ **Interfaces that feel simple even when the underlying product is complex**

I don't want to just make things look good.

I want to understand **what we're building, why we're building it, how people will use it, and whether it actually works.**

And yes, I am actually **amajaying.**

## Design Engineering

I like taking ideas beyond Figma.

I use code to prototype interactions, explore ideas, build experiments, and understand the technical constraints behind the products I design.

Currently working with:

- React
- JavaScript
- Tailwind CSS
- HTML & CSS

- Modern frontend tooling

I'm not trying to become a software engineer.
